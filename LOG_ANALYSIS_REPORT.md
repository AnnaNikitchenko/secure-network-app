# Звіт аналізу журналу

Статичні цифри попереднього звіту стосувалися попередньої JSON-версії сервера і не є результатом поточної реалізації. Локальні `logs/` збережені без змін; нові числа тут не вигадуються.

Щоб створити звіт із поточного JSONL журналу, виконайте:

```bash
python analyze_logs.py logs/server.jsonl --output logs/analysis.md
```

Для фільтрації за користувачем, подією та часом див. приклади в `README.md` і `TESTING.md`. До журналу не додаються паролі, JWT, OTP, приватні ключі чи вміст запитів.
